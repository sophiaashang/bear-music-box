# 小熊先生的八音盒

给兔子小姐的一些平安小事。一本温柔的网页小册子：拧动发条，八音盒响起来，小熊先生陪你翻开 14 页生活里的小事。

在线打开：https://sophiaashang.github.io/bear-music-box/

不想联网也行：下载本仓库里的 `index.html`，双击就能在浏览器里打开。

## 里面有什么

- 14 页场景：晚上出去玩、周末有局、感情里的事、想变得更好看、睡不好、钱包的事、手机和账号、被骗被威胁、一个人租房、上班的事、出远门、对自己好一点、心里不太舒服、突然出状况。
- 63 条小建议。原文一字未改，每条标了来源（第几节、第几条）和证据等级（A、B、C）。
- 每页有一幅小插画。点一下小熊先生，他会说一句话。
- 八音盒：拧发条、点小熊、翻页都有声音，右上角的铃铛随时开关。

## 内容从哪来

建议条目改编自开源书《高性价比人生指南》，原书使用 Unlicense：
https://github.com/eternity4719/HowToLiveBetter

这里只是换了一种温柔的读法，把 33 节按"遇到什么事"重新分成 14 页，并选出其中 63 条。想看完整的 614 条和全部文献，请去原书。

## 声音

页面里的音乐是巴赫《G弦上的咏叹调》（公版乐曲）。乐谱转译自 Mutopia Project 的公版 MIDI（该谱在文件头标注为 Public Domain）。音色由浏览器实时合成，没有使用任何录音，也没有使用真人配音或声音克隆。

## 隐私

页面不含统计代码，不收集任何数据。浏览器里只用本地存储记一件事：你有没有关掉声音。

唯一的联网请求是字体（霞鹜文楷，从 jsDelivr 加载）。离线时会自动用系统字体。
